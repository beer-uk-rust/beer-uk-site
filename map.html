Before you drop in

Know Before You Join

A few things about how Beer-UK actually runs, learned from running it.

✓

Give the map a few hours

Wildlife — deer, boar, wolves, bears — builds up gradually after a wipe. An empty-looking map in your first ten minutes isn't broken, it's just early.

✓

Watch chat for a restart countdown

That's an automated update warning, not a crash — the server comes back within a few minutes. Chat gets a heads-up well before it happens.

✓

Jump in early after a wipe

The whole map above is freshly generated for this seed, not a stock layout — first pick of monuments goes to whoever's on early.

✗

Don't count on offline raid protection

There isn't any — any base can be raided any time, including while you're offline. Plan your defences accordingly.

✗

Don't assume a restart means a wipe

Only the scheduled monthly force wipe (or an announced map wipe) resets the world — routine restarts just apply updates and keep your base intact.

✗

Don't expect pitch-black, hour-long nights

Ours are tuned shorter than vanilla Rust, so you're not stuck fumbling around in the dark for half the session.
